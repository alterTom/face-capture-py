# 0.2.0 桌面日志窗口和托盘

用户要求：安装后运行时有托盘和任务栏图标；关闭窗口隐藏至托盘；点击托盘恢复窗口，窗口实时显示采集日志；托盘右键可退出；窗口按钮可打开测试页。

## 设计和实现顺序

- [x] 增量日志读取：只读 capture.log/camera.log，支持 UTF-8 分段写入、文件轮转、只加载最近内容。窗口最多保留 5000 行。
- [x] PySide6 QtWidgets 管理窗口和 QSystemTrayIcon。主窗口是正常任务栏窗口；关闭到托盘后任务栏窗口消失，托盘图标保留；无托盘时回退为任务栏最小化。
- [x] HTTP 服务移动到工作线程；GUI 主线程只处理事件、轻量日志读取和状态展示。退出触发正常服务关闭、摄像头清理、GUI 退出。
- [x] Windows 单实例增加 show 事件；重复双击快捷方式恢复现有窗口。原 --stop 和 --open-demo 保留。
- [x] 默认启动显示窗口；--minimized、登录自启动和协议唤起仅驻留托盘。安装完成启动默认窗口。
- [x] 统一图标用于 EXE、安装器、窗口、任务栏、托盘。版本升级到 0.2.0。
- [x] 自动化覆盖关闭/恢复、测试页按钮、退出、日志刷新和轮转；实际 Windows 桌面及最终打包验证。

本次需求替代此前“不弹任何本地窗口”：本地窗口仅显示日志及服务状态，摄像头画面和抓拍结果仍只显示在浏览器。不新增网站白名单。

## 验证记录

- 完整构建通过：41 项 Python 测试、2 项 SDK 测试；PyInstaller 打包和打包后模型自检通过。
- Windows 日志窗口已启动并读取服务日志；关闭到托盘、恢复、退出及测试页按钮由 Qt 自动化测试覆盖。
